# Ankita Sharma &bull; Portfolio & Engineering Blog

> "No gatekeeping. No ego. Just builders helping builders."

Welcome to the source repository for my professional portfolio and mentorship blog platform. Built entirely from scratch with semantic HTML5, custom CSS architecture, and a meticulous editorial design system, this platform houses twenty comprehensive guides designed to demystify the software engineering recruiting pipeline for early career students and tech seekers.

---

## Design System & Aesthetics

The interface is engineered around a bespoke aesthetic palette that bridges warmth with modern technical precision:
* **Sakura Pink (`#f4a7b9`):** Accent highlights and brand signatures.
* **Warm Washi Cream (`#fdfbf7`):** Primary canvas backgrounds providing optimal reading contrast.
* **Roasted Chestnut Wood (`#3d2721`):** High contrast typography and structural borders.
* **Visual Effects:** Custom glassmorphism cards, wide editorial margins, clean author sign-off components, and fully responsive layouts.
